# Xúc xắc may rủi

Game mẫu của bộ công cụ phát triển Jagame: 2–6 người lần lượt gieo xúc xắc cộng điểm; gieo ra 1 là mất điểm lượt đó.

- **Luật chơi:** xem `howto` trong `manifest.json`.
- **Minh họa:** game theo lượt nhiều người, ngẫu nhiên tất định bằng `ctx.rng`, bảng điểm (`scores`), đầu hàng ở ván ≥ 3 người (`onResign`), máy chơi.
- **Tác giả:** Jagame. **Giấy phép mã:** MIT. **Tài sản:** icon và mặt xúc xắc tự vẽ bằng SVG/CSS, cùng giấy phép MIT.
