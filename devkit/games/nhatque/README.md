# Nhặt que

Game mẫu của bộ công cụ phát triển Jagame: 2 người lần lượt nhặt 1–3 que, ai phải nhặt que cuối cùng là thua.

- **Luật chơi:** xem `howto` trong `manifest.json`.
- **Minh họa:** game theo lượt (`mode: "turn"`), máy chơi (`bot`), gợi ý (`hint`), lý do kết thúc riêng (`reasons.que-cuoi`), tùy chọn ván.
- **Tác giả:** Jagame. **Giấy phép mã:** MIT. **Tài sản:** icon và hình que tự vẽ bằng SVG/CSS, cùng giấy phép MIT.
